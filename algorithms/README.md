# Algorithms

This directory contains research, implementation, and testing of algorithms used in the Micromouse robot.

## 1. Maze Solving Algorithms

Algorithms used to explore and solve the maze.

- **BFS (Breadth-First Search):** Explores the maze level by level.
- **DFS (Depth-First Search):** Explores one path as deeply as possible before backtracking.
- **Flood Fill:** Assigns distance values to maze cells to guide the robot toward the target.
- **Dijkstra:** Finds the minimum-cost path in a weighted graph.

## 2. Path Planning and Optimization

- Shortest path calculation.
- Path optimization.
- Turn and movement cost optimization.

## 3. Maze Exploration

- Wall detection.
- Maze mapping.
- Cell exploration and navigation.

## 4. Implementation

Algorithms will be implemented and tested in C before being integrated into the robot's STM32 firmware.
